# Tumor Heterogeneity documentation / 双语文档

Documentation-only publishing snapshot. Includes Chinese and English guides, design explanations and small examples. The implementation repository is currently private; source installation requires repository access.

本文档仓库仅包含中英文指南、设计原理与小型示例。实现代码仓库当前为私有，源码安装需要仓库访问权限。

Build / 构建：

```shell
python -m pip install -r docs/requirements.txt
python -m sphinx -W --keep-going -b html docs docs/_build/html
```
