# 先理解几个基本概念

不妨把肿瘤看成一块带有不同纹理的地形。平均海拔相同的两块地形，可能一个平坦、一个起伏很大；同样的高低区域，也可能集中成片，或交错散开。

CT 异质性分析试图描述这些差别。我们测量的是**图像表现**，不是直接读取组织学真相。

## CT、体素和掩膜

| 术语 | 通俗解释 | 在代码中的样子 |
| --- | --- | --- |
| CT 图像 | 三维的灰度地图 | `image[z, y, x]` |
| 体素 voxel | 三维图像中的一个小格子 | 数组中的一个值 |
| 掩膜 mask | 标记“哪些格子属于肿瘤”的地图 | 前景为 `True` 或正值 |
| ROI | 本次分析的区域 | `image[mask > 0]` |
| 间距 spacing | 小格子的实际边长，单位 mm | 例如 `(1, 1, 1)` |
| 特征 feature | 描述某一方面的数值 | 平均灰度、标准差、分形拟合值 |
| 标签图 label map | 把不同分区涂成不同编号的地图 | 0 为背景，正整数表示分区 |

数组形状一致，只能说明“格子数相同”。要确认 CT 与掩膜覆盖同一位置，还要核对间距、原点、方向和实际配准。

## 为什么不只看平均值？

假设两个简化 ROI 的灰度分别是：

| ROI | 示例值 | 平均值 | 直观差别 |
| --- | --- | --- | --- |
| A | 50, 50, 50, 50 | 50 | 灰度一致 |
| B | 20, 40, 60, 80 | 50 | 灰度分散 |

均值无法区分它们，标准差可以。但如果把 B 的像素位置重新打乱，直方图不变，空间结构却可能改变。因此需要同时观察**数值分布**与**区域排列**。

这是概念示例，不是 DHI 的测试输入；实际 DHI 还包含分位数裁剪等步骤。

## 分数、特征和空间图有什么区别？

- **score**：模型选定的摘要指标，适合先做病例间比较。
- **features**：解释摘要来自哪里，例如灰度变异、区域混合程度等。
- **label_map**：显示这些区域位于何处，用于空间检查。
- **details**：记录样本量、分块数量或拟合过程等信息。

可以把它们理解为“摘要、明细、地图和计算备注”。低分并不自动等于低风险，标签编号也不是病理诊断。

## 一个容易复现的起点

先在合成数据上跑通 DHI；再用少量真实病例核对空间位置与输出；最后固定参数运行队列。开始 [第一次计算](getting-started.md)。
