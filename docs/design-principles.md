# 为什么这样设计？

我们的核心思路是：**用多个可解释的视角描述同一肿瘤，并让每一步的输入和输出可检查。**

## 1. 七种模型回答不同问题

| 你想了解什么？ | 视角 | 对应模型 |
| --- | --- | --- |
| 灰度值有多分散？ | 数值分布 | DHI |
| 换一个观察尺度，灰度格局怎样变化？ | 多尺度切面结构 | BIH |
| 外形、表面和填充程度如何？ | 三维几何 | SHI |
| 肿瘤内部有哪些图像分区，它们如何混合？ | 生境及空间关系 | HAB |
| 局部纹理分区是否碎片化？ | 纹理与连通性 | THI |
| 肿瘤外圈各块组织有多不同？ | 瘤周环境 | PTH |
| 同时考虑多尺度特征与距离后，分区怎样组织？ | 特征与空间的联合关系 | ITH-FS |

这些问题相互补充，但不保证统计独立。多模型的价值在于比较不同描述，而不是简单堆叠数量。

## 2. 保留统一入口，也保留模型差异

各模型共享 `compute(image, mask)` 接口，以及 `score`、`features` 的基本返回约定。换模型不需要重写输入代码。

空间图是可选输出：DHI 的灰度摘要并不天然对应一张分区图，所以不强迫每个模型返回形式相同、含义却不同的图。批处理只展平表格字段，避免把整个队列的三维数组留在内存里。

当前这是模型层的一致性；带空间校验和统一配置文件的高层提取器仍在 [发布设计](package-design.md) 中规划。

## 3. 先让输入可比较，再比较分数

空间大小必须有物理含义。一个宽度为 5 个体素的环，在 1 mm 与 3 mm 数据里对应不同范围。当前多种模型使用单位间距，因此全模型实验应先统一到 1 mm 各向同性。

这一要求不代表所有数据都应无条件使用同一预处理。研究中仍应记录采集条件、插值方法、灰度裁剪、掩膜处理和纳入规则。模型接口本身不会替你完成配准。

## 4. 数值背后的计算方式

### DHI：先从“相对波动”开始

主分数是 ROI 灰度的变异系数，近似写作：

`CV = 标准差 / 平均值`

实现先按配置分位数保留灰度，再使用样本标准差，并在分母加小量以避免直接除零。局部变异系数等也输出为特征，但没有自动叠加成主分数。HU 可为负或接近零，此时 CV 必须结合均值解释。

### BIH：逐步改变观察格子的大小

当前实现选取最大肿瘤轴向切面，将 ROI 灰度归一化；对不同盒尺度计算有前景盒子的平均信号，再拟合对数关系，取负斜率作为 `fd`。因此它是本实现的信号尺度描述，不应直接等同于所有经典二值盒计数方法。输出的 `r2` 与残差可帮助判断拟合是否可靠。

### HAB：同时看“有哪些区域”和“如何排列”

GMM 与空间先验产生图像生境。评分综合组成熵、径向分层、核心与外层差异、边缘及全局混合、碎片化。当前 `H_HAB` 使用固定手工权重，并裁剪到 `[0, 1]`；这些权重不是当前队列训练得到的临床风险系数。

### THI：相似纹理是否形成完整区域？

THI 提取局部特征并进行 KMeans 聚类。对每类计算“最大连通块占该类总体积的比例”，再对类别求均值，最后用 1 减去这个均值。一个类别被分成多个碎片时，该类最大块的占比通常下降。

### PTH：观察肿瘤周围的差别

先构造瘤周环带，用 SLIC 分块，再比较各块的特征。主分数取 `PTH_CV_*` 的均值。外围组织必须在输入中保留；过小环带可能产生空特征和回退分数。

### SHI：用几何特征描述边界与形态

输出体积、表面积、球形度、凸包相关指标及分形描述。当前主分数对可用的 `1-sphericity`、`1-solidity`、`FD_surface/3` 取平均。它是手工组合的形态摘要，不是已经校准的生物学异质性标尺。

### ITH-FS：把特征相似与空间相近放在一起

不同尺度的体素特征构成近邻图。边权同时考虑特征距离与空间距离，经谱聚类得到分区，再从连通区域和空间一致性计算评分。它的“融合”发生在特征与空间关系层面，并非平均其他六个模型的分数。

`confidence_map` 来自谱空间中体素到所属聚类中心的相对距离；它表达算法内部的一致程度，不是概率校准结果。

## 5. 可解释性还需要结果检查

同一分数可能由不同结构产生。先检查输入和失败记录，再观察特征、拟合质量与空间分区，最后讨论病例或队列差异。我们保留这些中间描述，是为了让结果能被追溯，而不把一个数字当成全部结论。

当前仍需人工保存完整实验配置；自动来源记录、统一高层 API 和参数清理属于后续发布工作。实用参数见 [配置](configuration.md)，输出字段见 [模型与输出](models.md)。
