# 模型与输出

## 七种 ITH 模型

这些分数刻画不同维度，量纲和取值范围不同，不能直接平均或作为统一风险概率。

| 名称 | 方法概况 | 当前 `score` 的含义 | 空间输出 |
| --- | --- | --- | --- |
| BIH | 最大肿瘤轴向截面的信号加权盒计数 | 拟合的分形维数 `fd` | 无 |
| DHI | ROI 灰度统计与局部变异系数 | ROI 灰度 `CV` | 无 |
| HAB | 带空间先验的 GMM 生境划分 | `H_HAB` | `label_map` |
| PTH | 瘤周环带、SLIC 分块及块间差异 | `PTH_CV_*` 特征的均值 | `label_map` |
| SHI | 几何、凸包、分形与空隙度 | 可用的 `1-sphericity`、`1-solidity`、`FD_surface/3` 的均值 | 无 |
| THI | 局部体素特征与 KMeans 分区 | 聚类空间碎片化评分 | `label_map` |
| ITH-FS | 多尺度体素特征与空间谱聚类 | 分区异质性评分 | `label_map`, `confidence_map` |

ITH-FS 是独立计算模型，不是其余六个分数的加权融合器。DHI 使用有符号 HU 均值作 CV 分母，因此负值或接近零的均值会影响分数解释；不能机械地把数值大小当成跨队列通用排序。

各模型的直观含义与具体计算思路见 [设计原理](design-principles.md)。

## 单病例返回结构

```text
result
├── score           主分数，float；可能为 NaN
├── features        模型特征字典
├── details         可选，计算过程信息
├── label_map       可选，模型空间分区
└── confidence_map  可选，ITH-FS 算法内部置信图
```

并非所有模型都包含全部字段。置信图不是校准后的临床概率。不同模型、不同病例的标签编号不保证表示同一种组织，也不能直接当作病理标注。

HAB/PTH 的部分退化输入路径会返回 `score=0` 和空特征，不能仅凭零分认定低异质性，应同时检查 `features`、ROI 大小及 `details`。

## 批处理 CSV

| 列 | 内容 |
| --- | --- |
| `case_id` | 从文件名匹配得到的病例 ID |
| `score` | 主分数 |
| `feat_*` | 展开的特征 |
| `detail_*` | 可展平的标量详情 |
| `error` | 如果病例计算抛出异常，记录错误文本 |

病例间存在不同字段时，缺失位置以空值表示。批处理 CSV 不保存三维标签图和置信图。需要空间结果时，直接使用单病例 `compute()` 返回值，并自行保存参考图像的空间元数据。

## QuanTAV

QuanTAV 目前作为独立包安装，接收 CT（可选）、肿瘤掩膜与血管掩膜。其 `analyze_case()` 返回 `FeatureResult`，包含 91 个特征、分支信息及元数据；详细的结果访问方法见 [API](api.md)。其输出不属于上述七模型的统一 `score` 字典。
